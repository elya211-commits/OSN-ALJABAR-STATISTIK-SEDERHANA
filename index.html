Bab I Aljabar: Sub-Topik Statistik Sederhana

Rangkuman Teori & Formula Kunci

Dalam soal OSN Matematika tingkat Kabupaten/Kota hingga Nasional, bab **Statistik Sederhana** sering kali digabungkan dengan manipulasi aljabar, pertidaksamaan (AM-GM, Cauchy-Schwarz), serta sifat-sifat barisan.

Rata-rata (Mean) & Gabungan

$\bar{x} = \frac{1}{n}\sum_{i=1}^{n} x_i$

Rataan Gabungan:

$\bar{x}_{gab} = \frac{n_1 \bar{x}_1 + n_2 \bar{x}_2 + \dots + n_k \bar{x}_k}{n_1 + n_2 + \dots + n_k}$

Varians ($s^2$) & Deviasi Standar ($s$)

$s^2 = \frac{1}{n}\sum_{i=1}^n (x_i - \bar{x})^2 = \frac{1}{n}\sum_{i=1}^n x_i^2 - (\bar{x})^2$

Trik OSN: Gunakan bentuk $\sum x_i^2 = n(s^2 + \bar{x}^2)$ untuk hubungan aljabar kuadratik.

Pergeseran & Skalasi Data

Jika data $x_i$ diubah menjadi $y_i = a x_i + b$:

  • Mean/Median/Modus baru: $\bar{y} = a\bar{x} + b$
  • Jangkauan/Simpangan baru: $J_y = |a| J_x$ (abaikan $b$)
  • Varians baru: $s_y^2 = a^2 s_x^2$

Hubungan AM-GM & Varians

Untuk $x_i > 0$:

$\text{AM} \ge \text{GM} \iff \frac{\sum x_i}{n} \ge \sqrt[n]{x_1 x_2 \dots x_n}$

Kapan kesamaan berlaku? Ketika $x_1 = x_2 = \dots = x_n$ (Varians $s^2 = 0$).

Contoh Soal & Pembahasan OSN

Kategori: Sedang (Level OSK)

Soal 1: Rata-rata nilai matematika dari $n$ siswa adalah 80. Jika ditambah 5 siswa dengan rata-rata 90, rata-rata gabungannya menjadi 82. Berapakah nilai $n$?

Pembahasan / Solusi:

Gunakan rumus rata-rata gabungan:

$$\bar{x}_{gab} = \frac{n_1 \bar{x}_1 + n_2 \bar{x}_2}{n_1 + n_2}$$

$$82 = \frac{n(80) + 5(90)}{n + 5}$$

$$82(n + 5) = 80n + 450 \implies 82n + 410 = 80n + 450$$

$$2n = 40 \implies n = 20$$

Jadi, banyaknya siswa awal adalah 20 orang.

Kategori: Sukar / HOTS (Level OSP)

Soal 2: Diketahui $n$ buah bilangan real positif $x_1, x_2, \dots, x_n$ memiliki rata-rata $\bar{x} = 5$ dan varians $s^2 = 0$. Tentukan nilai dari $\sum_{i=1}^n x_i^2 + \prod_{i=1}^n x_i$ jika $n=4$.

Pembahasan / Solusi:

Ingat definisi varians $s^2 = \frac{1}{n} \sum_{i=1}^n (x_i - \bar{x})^2$.

Karena $s^2 = 0$ dan setiap $(x_i - \bar{x})^2 \ge 0$, maka haruslah $x_1 = x_2 = \dots = x_n = \bar{x} = 5$.

Untuk $n = 4$:

$$\sum_{i=1}^4 x_i^2 = 4 \times (5^2) = 4 \times 25 = 100$$

$$\prod_{i=1}^4 x_i = 5^4 = 625$$

$$Total = 100 + 625 = 725$$

Jadi, nilai akhirnya adalah 725.
